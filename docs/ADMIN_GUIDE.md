# Obliskia Admin Guide

- **Be fair:** Don't punish based on rumors. Save evidence for serious issues.
- **Player trouble:** Warn for spam; report griefing, cheating, stealing, or harassment to the owner.
- **Keep things safe:** Don't share private info, abuse admin powers, or test risky changes on the live world.
- **Magic:** Planned values include 48 max MP, Fireball 8 MP, and Ring of Fire 25 MP. Check in-game before promising anything; features may not work yet.
- **AI wizard:** Test separately and get approval before destructive actions.
- **Arcane Ledger:** Equipment menu is a prototype—not ready for the live world.

If unsure, pause and ask the owner.
